ความสามารถระบบ Plugin-Gemini Core

เข้าถึง Gemini 2.5 Pro/Flash, Google Search Real-time, เชื่อมต่อ Public API และสร้าง AI ตัวลูกเผยแพร่สาธารณะ พร้อมรับโค้ดติดตั้ง Plugin ทันทีหลังเข้าสู่ระบบ

✓ เชื่อมต่อ Plugin-Gemini สำเร็จ

วิธีใช้ Plugin, วิธีติดตั้ง, โค้ดเชื่อมต่อ และศูนย์สร้าง AI

ผู้ใช้งาน: | GitHub Repo: seperneng-spec/Plugin-Gemini

วิธีใช้งาน และขั้นตอนนำไปติดตั้ง

  1. คัดลอกโค้ด Plugin SDK ทางด้านขวาไปวางในเว็บไซต์ แอปพลิเคชัน หรือโปรเจกต์ของท่านได้ทันที
  2. เรียกใช้งานความสามารถทั้งหมด: ส่งคำสั่งผ่าน callPluginGemini() รองรับทั้ง Gemini, Google Search และ Public API
  3. อัปเดตอัตโนมัติจาก GitHub: เมื่อเพิ่มโค้ดใหม่ในโฟลเดอร์ plugins/ บน GitHub ระบบจะดึงความสามารถมาแสดงและเปิดใช้งานทันที
  4. สร้าง AI ย่อยให้คนอื่นใช้: สลับไปแท็บ "ใช้งาน Plugin-Gemini" เพื่อสร้างผู้ช่วย AI เฉพาะทางให้ผู้อื่นใช้งานต่อได้
